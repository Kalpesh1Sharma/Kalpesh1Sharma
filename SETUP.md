# Setup — Kalpesh's GitHub Profile README

GitHub shows a profile README when the public repository name exactly matches the username.

## 1. Create the repository

Create:

```text
Kalpesh1Sharma/Kalpesh1Sharma
```

Requirements:

- Public
- Use the username exactly as the repository name.

## 2. Upload this package

Upload these items to the root of that repository:

```text
README.md
assets/
scripts/
.github/
```

Do not upload the outer `kalpesh-github-profile` folder itself.

## 3. Run the activity visual once

After the files are on GitHub:

1. Open the repository.
2. Go to **Actions**.
3. Open **Update activity pulse**.
4. Click **Run workflow**.
5. Wait for it to finish.
6. Refresh your GitHub profile.

After that it refreshes automatically every day.

## Notes

- The SVGs adapt automatically to the visitor's OS light/dark theme.
- The activity pulse is generated inside your own repo, not by a third-party stats card service.
- The workflow uses the built-in `GITHUB_TOKEN`; no personal access token is needed.
- Keep this profile repository public. Your portfolio source repository can remain private.
